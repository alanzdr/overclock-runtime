# Changelog

## 0.1.0

First release: `/overclock` (setup for new and existing projects, and updates), `/overclock:run`
(cycles of planner → parallel waves of designers and developers → QA), `/overclock:feedback`, the
planner, designer, developer and QA agents, the `overclock-*` helper commands, a SessionStart status
line, and check presets for TypeScript web apps, Unity and generic stacks.
