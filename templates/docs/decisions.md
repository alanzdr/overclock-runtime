# Decisions

History of what was decided, when, by whom, and where the detail is. **What holds today is in the doc
of the subject** (`product.md`, `architecture.md`, `design-system.md`, `roadmap.md`, `CLAUDE.md`); read
it there. Open this file to know when something changed or what the user decided.

A new decision: the content goes in the doc of the subject, and only one line comes here (number, the
decision in one sentence, date, who, where). A replaced decision keeps its line, saying by which one
and when.

- **Decided by the user (`A#`):** hold until the user changes them. No agent contradicts them.
- **Decided by Claude (`D#`):** everything else. Any agent may change one when there is a reason,
  recording the new one and marking the old one as replaced. The user may change any of them
  (`/overclock:feedback`), and then it becomes an `A#`.
